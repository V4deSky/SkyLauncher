# SkyLauncher

# En🇬🇧
Run your `.gguf` files with AI using Sky Launcher, LLamaSharp was used to implement Sky Launcher, as well as the C# XAML stack.
I recommend using the Phi-3.5 model, as Qwen may produce errors on some models.

<img src="https://i.ibb.co/bjkvRWry/Screenshot-2026-11-16-183851.png" alt="Screenshot-2026-11-16-183851" border="0">

Instructions for launching a model in Sky Launcher:
1. Download the `.gguf` file with the AI
2. Move the `.gguf` file to the "SkyLauncher\models" folder, Example:
<img src="https://i.ibb.co/fz3v1J0v/Screenshot-2026-11-16-184244.png" alt="Screenshot-2026-11-16-184244" border="0">
3. Launch the application and click "Select Model" to select a model, and choose your AI `.gguf` file in it
<img src="https://i.ibb.co/jv6kWrHD/Screenshot-2026-11-16-183851.png" alt="Screenshot-2026-11-16-183851" border="0">
4. Enjoy the work of the AI.

# Ru🇷🇺
Запускайте свои `.gguf` файлы с ИИ с помощью Sky Launcher, для реализации Sky Launcher использовался LLamaSharp, так же стек C# XAML.
Рекомендую к использованию модель Phi-3.5, так как, на некоторых моделей Qwen может выдавать ошибки

<img src="https://i.ibb.co/bjkvRWry/Screenshot-2026-11-16-183851.png" alt="Screenshot-2026-11-16-183851" border="0">

Инструкция по запуску модели в Sky Launcher:
1. Скачайте файл `.gguf`, с Нейросетью
2. Переместите файл `.gguf` в папку "SkyLauncher\models", Пример:
<img src="https://i.ibb.co/fz3v1J0v/Screenshot-2026-11-16-184244.png" alt="Screenshot-2026-11-16-184244" border="0">
3. Запустите приложение и нажмите "Select Model", что бы выбрать модель, и выберите в ней ваш `.gguf` файл Нейросети
<img src="https://i.ibb.co/jv6kWrHD/Screenshot-2026-11-16-183851.png" alt="Screenshot-2026-11-16-183851" border="0">
4. Наслаждайтесь работой Нейросети.
